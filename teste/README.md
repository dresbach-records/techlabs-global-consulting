
# Ambiente de Teste para Novos Painéis

Este diretório contém os novos painéis de Cliente e Administrador em desenvolvimento.

## Acesso

Para acessar os painéis, utilize a página de login temporária:

- **URL de Login:** `/test/login`

Nesta página, você pode escolher o tipo de conta que deseja acessar:

- **Cliente:** Selecione "Cliente" e clique em "Entrar" para ser redirecionado ao painel do cliente (`/test/client/dashboard`).
- **Administrador:** Selecione "Admin" e clique em "Entrar" para ser redirecionado ao painel do administrador (`/test/admin/dashboard`).

## Observações

- Este é um ambiente de desenvolvimento isolado. As alterações feitas aqui não afetarão o site principal.
- O cabeçalho e o rodapé do site principal não são exibidos nas páginas de teste.
